# Chinese Voiceover Pause Skill

为中文口播、新闻评论、视频解说和旁白文稿智能添加 `[short pause]` 与 `[pause]` 标记。

## 功能

- 根据语义和口播节奏自动决定停顿位置
- 区分短停顿与长停顿
- 不机械按标点或字数插入
- 默认只添加标记，不改写原文
- 可参考用户给出的示例密度

## 标记含义

- `[short pause]`：句内换气、轻转折、局部强调
- `[pause]`：段落切换、强转折、观点落点、重要结论

## 使用方式

安装或加载该 Skill 后，直接提供中文文稿并说明“添加口播停顿标记”即可。

示例：

```text
请给下面这段口播稿添加 [short pause] 和 [pause]，位置与频次由你决定：

制度本身没有问题，但只要资格具有稀缺价值，市场就会寻找绕过它的方法。
```

## 输出示例

```text
制度本身没有问题，[short pause]但只要资格具有稀缺价值，市场就会寻找绕过它的方法。[pause]
```

## 设计原则

- 自然口播优先
- 语义完整优先
- 密度随内容变化
- 不连续堆叠停顿标记
- 不擅自修改正文
